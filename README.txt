EVENT REGISTRATION WEBSITE - JAVASCRIPT MICROPROJECT

PROJECT OVERVIEW
RegiSphere is a simple, responsive event registration website made using HTML, CSS, and JavaScript. Visitors can view upcoming events, submit participant details, receive an on-screen confirmation, and see recent registrations.

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html, or open it in a web browser.
4. Select an event, fill in the form, and click Complete Registration.

PROJECT FILES
- index.html  : Website structure and registration form
- style.css   : Design, layout, and responsive styling
- script.js   : Event display, form validation, and registration storage

JAVASCRIPT CONCEPTS USED
- Arrays and objects to store event information
- Functions to render events and registrations
- DOM selection and manipulation
- addEventListener() for form submission and button clicks
- Form validation using required, minlength, type, and pattern
- localStorage to save demo registrations in the browser
- JSON.stringify() and JSON.parse() to store and retrieve data
- Date object to record registration time

IMPORTANT NOTE
This is a front-end educational demonstration. Registration details are saved only in the browser's localStorage. There is no database, server, email service, or online submission. Do not enter sensitive personal information.

CUSTOMIZATION
Edit the events array near the top of script.js to change event names, dates, times, venues, icons, and descriptions.
